# Pepperoni Apps — Windows releases

Официальные сборки **Fixture Studio** и **StreamDesk**. Автор: **Pepperoni**.

## Скачать

Открой [Releases](https://github.com/PepDominator/pep-apps-releases/releases) и выбери EXE нужной программы либо полный `Native-Windows.zip`. Исходники доступны отдельными `Native-Source.zip`.

## Обновление одной кнопкой

Начиная с Fixture Studio **2.4.1** и StreamDesk **2.3.3**:

1. Открой **Настройки / Параметры → Обновления программы**.
2. Репозиторий по умолчанию: `PepDominator/pep-apps-releases`.
3. Нажми **Проверить обновления**, прочитай изменения, затем **Скачать обновление**.
4. Нажми **Установить и перезапустить**. Программа дождётся завершения текущей очереди, повторно сохранит данные и перезапустится.

Скачивание проверяется по размеру, SHA-256 GitHub и формату Windows x64 EXE. Предварительные и черновые релизы пропускаются. Каждая программа выбирает только свои файлы.

Папки данных, планы, BAT и скачанные записи не заменяются. Рядом с действующим EXE сохраняется `имя.exe.previous.exe`. Путь основного EXE сохраняется для ярлыков и связи с браузерными расширениями, поэтому имя файла может содержать прежний номер версии; актуальная версия указана внутри приложения.

При неудачной замене восстанавливается прежний EXE. Если новая версия не подтверждает запуск интерфейса, помощник возвращает предыдущую. Будущие таймеры остаются на диске; на время перезапуска новые задачи приостановлены.

Сохрани несохранённые команды перед установкой. Ожидание установки можно отменить; работающие загрузки продолжаются. Программа должна оставаться открытой до завершения обновления. Проверка выполняется по кнопке, без фоновой отправки расписаний, ссылок, ключей и настроек.

## Для публикации

В стабильный публичный релиз добавляй файлы с точными именами:

- `FixtureStudio-X.Y.Z.exe`
- `StreamDesk-X.Y.Z.exe`

Файлы архивов и исходников могут находиться в том же релизе. Версии приложений независимы; не обязательно выпускать их одновременно. GitHub должен завершить загрузку EXE и предоставить поле `digest` с `sha256:...`. Если его нет, встроенный установщик откажется применять файл.

Workflow **Windows updater verification** проверяет реальную замену работающего Windows EXE и откат при неудачном запуске по опубликованным исходникам релиза. Сначала можно публиковать предварительный релиз, дождаться успешной проверки и только затем сделать его стабильным.
